# Claude Skills

Claude Code can use skills from this folder.

Guidelines:
- Put Claude-compatible skills here.
- Each skill should be a folder containing `SKILL.md`.
- Do not install every skill blindly.
- Keep only relevant project skills in active use.
- Prefer project-specific skills over generic ones when both exist.
- Read only the specific `SKILL.md` files needed for the current task.
- Use `Original Claude code skills/` for source preservation, not routine task execution.

This folder currently acts as the project-facing Claude skill library mirror.
