# HANDOFF

Use these templates for structured transitions between agents. Replace placeholders and remove irrelevant lines rather than inventing a new format.

Rules:
- Keep only one active handoff section unless parallel work truly requires multiple distinct handoffs.
- If a handoff is superseded, replace or close it rather than stacking stale instructions.
- Handoffs should be compressed but actionable.
- Always include explicit acceptance criteria, risks, and what the next agent should do first.
