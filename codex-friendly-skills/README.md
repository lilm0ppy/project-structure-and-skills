# Codex-Friendly Skills

Codex-friendly skills live here.

Guidelines:
- Skills should be agent-neutral where possible.
- Codex should read relevant `SKILL.md` files before major tasks.
- Skills should not rely on Claude-specific slash commands.
- Each skill should include Codex usage notes, trigger guidance, and a validation checklist.
- Do not load every skill automatically; select only the skills that match the task.
- Use this folder as the default Codex-facing skill library.
- Use `Original Codex skills/` only when auditing or refreshing the mirrors.

This folder currently acts as the project-facing Codex skill library mirror.
